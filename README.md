# pink-rivers-watchdog

Uptime-сторож сайта pink-rivers.ru и ретранслятор служебных алертов в Telegram.
Запускается в GitHub Actions раз в 5 минут (`.github/workflows/watchdog.yml`).

Репозиторий публичный только ради бесплатных минут Actions. Токены и адресаты хранятся в
секретах репозитория, в логи пишутся только статусы. Исходник поддерживается в основном
(приватном) репозитории, сюда публикуется скриптом. Правки вносить там, а не здесь.
